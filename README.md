# WS101 Activity 1 — Personal Web Page

A hand-written HTML + CSS personal web page built for **Web Systems and Technologies 1 (WS101)**, Quezon City University. No frameworks, no build tools, no JavaScript — the show/hide boxes and smooth nav scroll are done with plain HTML and CSS features the browser already supports natively.

## Live Demo

https://kianoroku18ino.github.io/ws101-personal-portfolio/

## Sections

| Section | What's in it |
|---|---|
| Hero | Name, program, profile photo |
| About Me | Bio, QCU/ROTC links, hobbies, currently-playing games, QCU Vision/Mission/Values |
| Academics | Honor cards + my Grade 10→12 report cards, each inside a `<details>` box |
| Media | Two real YouTube embeds (favorite song, favorite video) |
| Connect | A `mailto:` contact form and direct links (Gmail, GitHub, Facebook) |

## File Structure

```
260003GalaridoPortfolio.html   — the page
260003GalaridoStyle.css        — all styling (external stylesheet, per the assignment's naming rule)
assets/images/                 — profile photo, QCU/ROTC/school seals
```

## Tech

Plain HTML5 + CSS3. Google Fonts (Spectral, Public Sans). No JavaScript, no build step — open `260003GalaridoPortfolio.html` directly in a browser to view.
